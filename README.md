# Simon 3D

A Simon-style memory game with a 3D, interactive light board rendered in Three.js and a React interface.

## Requirements

- Node.js 20 or later
- npm
- A browser with WebGL enabled

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Play

1. Select **Start game**.
2. Watch the pads light up in sequence.
3. Repeat the pattern by clicking or tapping a 3D pad, or by selecting its matching color button.
4. Each completed round adds another color. Your best completed round is saved in this browser.

## Production build

```bash
npm run build
npm run preview
```
